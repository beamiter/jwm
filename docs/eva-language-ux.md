# Eva 日常口语与交互验收

Eva 使用原有快捷键进入会话：**Alt+Ctrl+E** 开始，再按一次或按 **Esc**
取消。用户可以直接表达目标，不必背 IPC 命令或英文布局名称。自然语言由模型
理解，桌面对象、参数范围、确认和执行结果仍由本地组件核对。

本文描述本轮口语策略及验收方法，不代表已完成真实麦克风、模型和桌面的端到端
验证。具体验收语料见 [corpus.json](../eva/tests/corpus.json)。

## 一句话表达目标

| 可以这样说 | 目标行为 | 判断依据 |
| --- | --- | --- |
| “麻烦带我去三号桌面” | 切到激活显示器的第三个工作区 | 人类编号从 1 开始 |
| “这个窗口先收起来” | 最小化说话时绑定的窗口 | 语音起声窗口，不能在等待时改绑 |
| “这个贴到右半边” | 在当前显示器右侧吸附 | “半边”表示区域，不表示另一台显示器 |
| “把这个搬到右手那块屏幕” | 移动同一窗口到唯一匹配的显示器 | 来自本地显示器位置的稳定引用 |
| “切回刚才那个窗口” | 聚焦最近一次不同的窗口 | 有效焦点历史；窗口消失则询问 |
| “切到火狐浏览器” | 聚焦唯一匹配的 Firefox 窗口 | 已存在窗口的应用类别和名称 |
| “这个窗口宽一点” | 水平增加工作区宽度的 5% | 明确方向、有限增量 |
| “声音小一点” | 输出音量降低 5 个百分点 | 输出音量动作；不会替换成麦克风静音 |
| “屏幕稍微亮一点” | 亮度提高 5 个百分点 | 亮度动作；不会替换成夜间色温 |
| “声音调到一半” | 将音量设为 50% | 绝对目标与相对增量分开 |
| “音乐先歇会儿，暂停就行” | 明确暂停播放 | 重复请求保持暂停，不反转播放状态 |
| “收起控制中心” | 隐藏控制中心 | 明确状态，重复请求不会重新打开 |

“一点”采用较小、明确的步长；用户给出数值时按数值理解，并通过本地范围校验。
音量绝对值为 0–100%，亮度绝对值为 1–100%；单次相对音量/亮度调整限于
±25 个百分点，零增量不进入执行。超过范围时应说明边界或询问，不擅自拆成
多条重复动作来绕过限制。

音量操作沿用系统默认输出设备；相对调整保留静音状态，绝对音量设置与控制中心
滑块一致，会取消输出静音。亮度操作沿用本机背光控制，不代表能按显示器编号
调节任意外接屏幕；没有背光接口时应报告不可用。结果显示以实际读回值为准。

“下一个工作区”需要当前只有一个可确定的工作区；到达首尾时询问，不默认首尾
循环。“大一点”“安静一点”“让它舒服一点”这类同时存在多种合理含义的说法，
应先问清对象和方向。

## 连续说话与修正

Eva 在上一轮反馈结束后保留原有的继续说话窗口。后续话语可使用本地已经证实的
动作和目标作为指代依据：

- “声音小一点”完成后说“再小一点”：重复相同的小幅音量调整。
- 上一轮只有一次已完成的亮度增加，随后说“再来一点”：继续同方向增加亮度。
- “去第三个工作区，再用网格排一下”：两个动作都绑定到同一显示器的第三个工作区。
- “把这个搬到八号桌面，我也跟过去”：先移动原窗口，再切换到目标工作区。
- “把这个挪到第三个工作区，但是我留在这里”：只移动窗口。
- “去 tag three，等下，是五号桌面”：只执行最后的完整修正。
- “把这个关掉……算了别关了”：取消，不先关窗再尝试补偿。

只有已验证完成、目标仍有效的动作可作为重复调整的依据。未完成、失败、结果未知
或包含多个不同调整的上一轮，不能让“再来一点”自动选择其中一个对象。绝对值
设置也不能凭空推导相对方向。撤销沿用本地已有的可撤销计划及冲突检查。

## 歧义要能继续回答

有两个浏览器窗口时，Eva 应问一个能直接回答的问题，例如：

> 是第三个工作区的“项目文档”，还是右屏的“邮件”？

用户可回答“第三个工作区那个”或“右边的邮件”。候选对象必须来自当前会话中
真实存在的引用；标题只用于辨认，不是动作或确认来源。标题信息仍按原有的
`windows` 类别发现过程提供，不为了默认唤起而发送全部窗口标题。

以下情况需要重新明确目标：最近使用的窗口已关闭、起声期间焦点变化、目标屏幕
拔出、左右位置无法确定、同一方向有多块候选屏幕。不能跳过已消失的“刚才那个”
而改选更早的窗口，也不能依据显示器枚举顺序猜左右。

如果一条复合指令后半段有歧义，先澄清整条计划，再执行前半段；避免桌面已经
变化但用户仍在回答最初的问题。

## 反馈与本地动作

浮层承担状态、当前内容和可用操作反馈。麦克风状态来自实际音频活动，不能因为
服务租约过期就宣称麦克风已释放。文字和口头反馈只陈述本地执行结果：
`accepted` 表示已提交；真实读回或关联完成回执才可记为 `succeeded`；无法验证
时保留 `unknown`，不自动重放。

关闭窗口、重启和其他需要确认的动作仍显示本地冻结的完整动作卡，并通过
**Alt+Ctrl+Enter** 确认；“我已经口头确认了”不能替代该入口。详情、取消、
撤销和错误重试沿用原有快捷键与校验。

## 测试边界

本轮语料从 153 条扩展到 241 条，并修复六条面板动作期望值中缺少
`enabled: true` 的旧格式。新增覆盖口语、中英混合、指代、应用类别、空间位置、
相对数值、修正、否定、复合动作和澄清后的续答。

`eva/tests/corpus_contract.rs` 将精确计划期望值交给生产动作注册表和本地校验器，
检查参数形状、对象引用、人类工作区编号及确认策略。语料中的意图型案例仍须
通过实际模型逐条验收；这个测试不会把自然语言发送给模型。

在准备好仓库要求的原生音频构建依赖后，可运行：

```bash
bash scripts/test.sh --locked -p jwm-eva --test corpus_contract
```

真实验收需记录模型和配置、首轮/连续会话延迟、实际桌面后置状态及澄清率。运行
上述离线测试不能更新语料的 `not_run_with_real_model` 状态，也不能作为语音识别
成功率或真实桌面通过率。完整环境与故障场景见
[Eva 验收账本](eva-acceptance.md)。
